# Roadmap

## Done

- Headless storefront on Shopify, guides, reviews with themes, compare, LGBTQ+ category
- AI advisor (Claude + tools + rules + fallback) as a site-wide widget
- Build-your-ritual bundles
- Event tracking + Insights dashboard
- Agent API with keys
- Retail partner portal on Shopify B2B with kits, tiers, freight, draft orders
- Demo sign-in with server-side role checks
- ERP sync (simulated warehouse, real Shopify inventory push, order export)
- Deployed to Vercel; renamed to Afterglow; documentation

## Next (before the office visit)

1. Team roles (Design, Marketing, Operations, Admin) with demo personas, a central permission helper and a `/team` dashboard
2. Product Feedback Intelligence (`/team/product-intelligence`)
3. AI Marketing Assistant (`/team/marketing-assistant`)
4. Tests for permission checks (Vitest)

## Later

- Shopify Customer Account API: shopper login, order history, reorder, saved products
- Real retail buyer login through Shopify B2B; wholesale access applications
- Staff login with an auth provider, invitation-only, audit log
- Personalization with explicit consent controls
- Enhanced insights (feedback trends, retailer activity)
- Marketplace (Amazon) listing feed; MAP monitoring
- Full test suite (Vitest + Playwright)

The full long-term spec is in [master-plan.md](master-plan.md).
